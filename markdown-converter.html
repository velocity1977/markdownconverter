Engineering Principles

Built for users who care about data isolation, layout fidelity, and deterministic output.

01 / AIRGAPPED INTEGRITY

Zero Network Footprint

Operates in complete offline isolation. No phone-home telemetry, no remote API calls, and zero bytes uploaded to third-party cloud infrastructure.

02 / ASSET DECOUPLING

Figure & Image Isolation

Embedded vectors and raster bitmaps in PDFs, Word docs, and PowerPoint slides are extracted directly into a sibling _assets folder and automatically linked.

03 / HEURISTIC REPAIR

Symbol Font Normalization

Translates legacy PDF Private-Use-Area (PUA) symbol glyphs (e.g. angle marks, Greek letters, math operators) into compliant UTF-8 characters.

04 / ASYNC WORKERS

Folder & Queue Processing

Queue hundreds of documents or point directly at recursive directory trees. PyQt6 background QThread workers keep the interface fluid and responsive.

05 / BATCH DECRYPTION

Password-Protected PDFs

Supply a session passphrase to decrypt and convert password-secured documents across your entire queue in a single unattended pass.

06 / DESKTOP NATIVE

OS Theme Synchronization

Queries Windows DWM and Registry personalization APIs at startup to seamlessly match your system Light or Dark mode with native title bar tinting.

Frequently Asked Questions

Straightforward answers about licensing, security, and formats.

Does any document data leave my machine?

No. Conversions run 100% locally on your CPU using bundled Python parsing runtimes. The application has zero outbound network requests and no analytics telemetry.

Where do extracted images get saved?

When "Extract Figures" is enabled, graphics and photos are saved in a subfolder named <filename>_assets/ alongside your generated .md file.

How does it handle password-protected PDFs?

Enter the passphrase into the "PDF Password" input in the application before clicking convert. The engine will attempt unlocking each encrypted file in your batch.

Why is this open-sourced under AGPL-3.0?

The PDF conversion backend utilizes pymupdf4llm (and underlying PyMuPDF), which is licensed under GNU AGPLv3. We fully open-source our codebase in strict compliance.
